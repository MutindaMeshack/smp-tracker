# SMP Tracker

A daily performance tracker for the Self-Made Protocol (SMP) fitness program.
Logs sleep, water intake, and step count, and tracks progress over time.

## What It Does

- Accepts daily check-in data (sleep hours, water glasses, steps)
- Prints a summary of the day's tracking data
- Includes supporting modules for coaching messages and reporting

## Setup

```bash
python tracker.py
```

## Files

- `tracker.py` - main tracking script
- `coaching.py` - coaching message logic
- `report.py` - weekly report generator
- `api_client.py` - API integration placeholder
- `prediction.py` - basic step prediction function
